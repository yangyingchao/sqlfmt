GOTCHAS TO WATCH
================

1. TEXT Type Restoration
   - Simple counting may fail
   - Solution: Track positions if issues arise

2. Parser API Differences
   - sqlparser-rs != CockroachDB API
   - Solution: Careful testing needed

3. Regex Replace Closures
   - Rust doesn't allow mutable captures
   - Solution: Use manual iteration

4. WITH Compression
   - Heuristic may have edge cases
   - Solution: Refine as needed

5. Cache Eviction
   - Not true LRU in Go version
   - Solution: Use proper moka LRU

6. Case Functions
   - Can't store closure function pointers
   - Solution: Enum-based dispatch
